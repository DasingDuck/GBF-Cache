浏览器自己有 HTTP 缓存：资源已经存在 Edge 里，游戏就不会再发起网络请求， 自然也不会写入这个目录。想让它快速填充，可以：
① 在 Edge 里清一次「缓存的图像和文件」（设置 → 隐私 → 清除浏览数据）；
② 或在游戏页面按 Ctrl+Shift+R 强制刷新；
③ 或去游戏里打开一张没进过的关卡。
点「测试完整缓存」（在下方「维护与诊断」卡里）可以立刻验证写入链路是否正常。
