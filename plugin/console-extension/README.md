# 碧蓝幻想缓存控制台（独立侧边栏扩展）

这是一个**独立扩展**：点击浏览器工具栏图标，在侧边栏里打开本地缓存程序的控制台。

它和 `plugin/edge-extension/` **不是同一个扩展**，两者职责分开：

| | `edge-extension`（原有） | `console-extension`（本目录） |
|---|---|---|
| 作用 | 把游戏资源请求交给本地缓存代理 | 在侧边栏显示控制台 |
| 权限 | `proxy`、`alarms` | `sidePanel` |
| 是否改代理/PAC | 是 | **否** |
| 能否单独使用 | 可以 | 可以（需要缓存程序在运行） |

两个扩展可以同时安装，互不覆盖。

## 安装

1. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）。
2. 打开右下角（或右上角）的「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本目录 `plugin/console-extension`。
4. 在工具栏的扩展列表里把「碧蓝幻想缓存控制台」固定出来。

## 使用

1. 先启动「碧蓝幻想本地缓存程序」（控制台地址 `http://127.0.0.1:8799/`）。
2. 点击工具栏上的扩展图标，侧边栏就会显示控制台。
3. 侧栏宽度可以拖动边缘调整；控制台在 ≤560px 时会自动启用紧凑布局
   （页眉两行、指标卡两列、设置面板可滚动），桌面宽度下保持原样。

## 侧栏界面

主视图只显示 **5 项实时指标**（缓存命中 / 回源下载 / 新写入缓存 / 异常拦截 / 错误）
和 **实时日志**。页眉的 **☰ 菜单**按类型打开其余内容：

| 菜单 | 内容 |
|---|---|
| 操作 | 启动游戏 / 启动加速器 / 更新日档位 |
| 缓存 | 缓存库概况 / 缓存目录 / 缓存构成 / 按类型清理 |
| 网络 | 系统代理 / 命中来源 / 回源耗时 |
| 维护与诊断 | 最近错误 / 体检 / 导出 / 自检 |
| 设置 | 启动项 / 缓存开关 / 悬浮窗 / 外观 |

子页面左上角「← 返回监控」回到主视图；子页面右上角的 ☰ 可以切换类别。
这些卡片不是复制品 —— 服务端只发一份 `dashboard.html`，切类别只是把同一批
DOM 节点搬进子页面，所以数字和按钮状态始终与桌面控制台一致。

侧栏里显示的就是服务端那份 `dashboard.html`，没有第二份副本。侧栏、独立窗口、
普通标签页看到的数字和操作完全一致。

## 说明

- **端口固定为 8799**：与现有代理扩展、托盘、控制台一致。如果通过
  `GBFCACHE_PORT` 改了端口，需要同时改 `sidepanel.js` 里的两条 URL 和
  `manifest.json` 的 `host_permissions`。
- **服务没启动时**：侧栏显示「缓存服务未启动」并自动重试；启动程序后回到侧栏
  即可，也可以点「立即重试」。
- **剪贴板**：iframe 上声明了 `allow="clipboard-write; clipboard-read"`，控制台里的
  「复制 .ext」才能用。
- **悬浮窗**：控制台的 SSE 连接会被服务端视为“控制台已打开”，因此侧栏开着时
  悬浮监控窗会自动收起，关掉侧栏后恢复。这是服务端原有的联动逻辑。
- **浏览器要求**：Chromium 114+（Edge / Chrome）。Firefox 的侧边栏是另一套
  `sidebar_action` API，本扩展不适用。
- **代理能力不在这里**：本扩展不申请 `proxy` 权限，也不读取游戏流量。需要扩展
  接管代理时，仍然使用原来的 `edge-extension`，或依赖系统 PAC。

## 文件

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单：`sidePanel` 权限、侧栏入口、图标 |
| `sw.js` | 只做一件事：让点击图标打开侧栏 |
| `sidepanel.html` | 侧栏壳：离线提示 + iframe |
| `sidepanel.js` | 探活 `/health`，服务在线后加载控制台 |
| `sidepanel.css` | 侧栏壳的深浅色样式 |
| `icon.png` | 扩展图标（与程序主图标一致） |
