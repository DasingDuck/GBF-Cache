# 碧蓝幻想缓存控制台（浏览器统一扩展）

这是本程序在浏览器侧的**唯一扩展**，一个扩展全包三件事：

| 职责 | 说明 |
|---|---|
| 侧边栏控制台 | 点击工具栏图标，在侧边栏里看本地缓存程序的实时控制台 |
| 代理 / PAC | 把浏览器的代理设置跟随服务端 PAC（资源走缓存、接口直连、其余交回加速器）；代理控制权被其他扩展抢占时在图标上打红色 `!`，悬停看原因 |
| 跟随浏览器 | 浏览器一开就自动拉起本地程序、浏览器一关程序跟着退（需先运行 `register-native-host.ps1` 注册；未注册时前两项照常工作） |

> **历史**：V1.x 时代这是两个扩展 —— `edge-extension`（v2.2.1，管代理/PAC/跟随）和
> `console-extension`（v1.1.1，只管侧栏）。2026-10-25（程序 V4.24.0）按用户要求合并为
> 本扩展，以侧栏扩展为主体。manifest 里的固定 `key` 沿用原代理扩展的，因此
> **扩展 ID 不变**（`aflaenjbhecnfjclgbgplmpacjnealln`），原生宿主注册无需重做。

## 安装（从旧版迁移）

1. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`），开「开发人员模式」。
2. **移除旧扩展**：旧的「碧蓝幻想本地缓存程序」（代理扩展）和旧版「碧蓝幻想缓存控制台」
   都要移掉（合并版与旧代理扩展共用同一个 ID，不移除装不上新的）。
3. 「加载解压缩的扩展」选择本目录 `console-extension`。
4. 要用「跟随浏览器」就先跑一次 `..\register-native-host.ps1`（程序 V4.23.0+），再重启浏览器。

## 使用

- 点扩展图标 → 侧栏显示控制台；栏宽可拖动，≤560px 自动紧凑布局。
- 代理自动跟随：无需配置；图标悬停显示「正在跟随服务端 PAC」即正常。
- 服务没启动时：侧栏显示「缓存服务未启动」并自动重试；装了跟随模式则浏览器一开服务就来了。

## 侧栏界面

主视图只显示 **5 项实时指标**（缓存命中 / 回源下载 / 新写入缓存 / 异常拦截 / 错误）
和**实时日志**。页眉的 **☰ 菜单**按类型打开其余内容：

| 菜单 | 内容 |
|---|---|
| 操作 | 启动游戏 / 启动加速器 / 更新日档位 |
| 缓存 | 缓存库概况 / 缓存目录 / 缓存构成 / 按类型清理 |
| 网络 | 系统代理 / 命中来源 / 回源耗时 |
| 维护与诊断 | 最近错误 / 体检 / 导出 / 自检 |
| 设置 | 启动项 / 缓存开关 / 悬浮窗 / 外观 |

子页面左上角「← 返回监控」回到主视图。这些卡片不是复制品 —— 服务端只发一份
`dashboard.html`，切类别只是把同一批 DOM 节点搬进子页面，侧栏、独立窗口、普通
标签页看到的数字和操作完全一致。

## 说明

- **端口固定为 8799**：与服务端、托盘、控制台一致。如果通过 `GBFCACHE_PORT` 改了端口，
  需同时改 `sidepanel.js` 里的两条 URL、`sw.js` 里的两条 URL 和 `manifest.json` 的
  `host_permissions`。
- **代理的关键纪律**（继承自旧代理扩展）：先同步写兜底 PAC 再升级为服务端 PAC；服务端
  PAC 拉取后剔除注释并保证纯 ASCII（Chromium 的 `pacScript.data` 拒绝非 ASCII，旧版
  服务端因此静默失败过）；游戏接口（/rest/ 等）绝不接管。
- **跟随浏览器的机制**：`chrome.runtime.connectNative` → 浏览器拉起 `GBFCache.exe` →
  浏览器退出时终止它。跟随模式下程序不拉托盘/悬浮窗（生命周期随浏览器）。
- **剪贴板**：iframe 上声明了 `allow="clipboard-write; clipboard-read"`，控制台里的
  「复制 .ext」才能用。
- **悬浮窗联动**：侧栏开着时控制台的 SSE 连接会让悬浮监控窗自动收起，关掉侧栏后恢复
  （服务端原有逻辑）。
- **浏览器要求**：Chromium 114+（Edge / Chrome）。Firefox 不适用（侧边栏与原生宿主
  均为 Chromium 机制）。

## 文件

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单：`sidePanel`+`proxy`+`alarms`+`nativeMessaging` 权限、固定 `key`、侧栏入口 |
| `sw.js` | 统一 Service Worker：开侧栏 + 代理/PAC 跟随 + 原生宿主连接 |
| `sidepanel.html` | 侧栏壳：离线提示 + iframe |
| `sidepanel.js` | 探活 `/health`，服务在线后加载控制台 |
| `sidepanel.css` | 侧栏壳的深浅色样式 |
| `icon.png` | 扩展图标（与程序主图标一致） |
