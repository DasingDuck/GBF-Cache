安装使用

三步就能用

不需要装运行库，不需要浏览器插件，也不改动游戏本身。

  1. 1

    解压到固定文件夹

    把压缩包整个解压出来，别只把里面的程序单独拿走 —— 旁边那几个文件都是配套的。路径里建议不要用特殊符号。

  2. 2

    装一次随包的证书

    程序需要这张证书才能看懂游戏和电脑之间的来往。双击证书文件 → 按提示一路下一步，注意选到「受信任的根证书颁发机构」。不需要管理员权限，装完请把浏览器完全关掉再打开。

  3. 3

    双击启动，正常玩

    右下角出现小图标，控制台窗口点「启动游戏」即可。判断它在工作最简单的一招：看「缓存命中」在不在涨。

退出请用托盘菜单里的「退出」，不要强行结束进程。程序启动时会接管一次系统里的上网设置，优雅退出才会把它还原回去。

程序特性

它凭什么又快又稳

下面每一条都是程序里真实存在的机制，不是宣传词。

零依赖 · 单文件

只用 Node 内置模块写成，一个 exe 就是全部。不装运行库、不写系统目录、不注册服务。

只碰资源，不碰账号

只接管 /assets/ 的 GET/HEAD；登录、抽卡等 /rest/ /ob/ /od/ 接口一律直连，/user/ 绝不拦截。

认得出「资源版本」

游戏的资源 URL 带 ?1729002592 这类版本参数。版本不一致的文件绝不当命中，避免游戏判定版本不符而反复整页重载。

换版本时少下很多

游戏更新资源版本时，程序会先跟源站确认「哪些文件真的变了」——没变的直接沿用本地那份，只有真变了的才重新下载。更新日要下的量因此小得多。

能和加速器一起用

程序会自己认出你正在用的加速器，把需要联网的那部分流量交给它走 —— 读缓存走本地、要联网走加速，两边各管一段，互不打架。

一切都看得见

命中、回源、新写入、异常拦截、错误五个计数实时推到控制台和桌面悬浮条，命不命中一眼就知道。

常见问题

你可能想问的

需要再装别的东西吗？

不需要。不用装任何额外的运行库，也不用装浏览器插件。下载、解压、拖出来就能跑。

用哪个浏览器？

推荐使用 Edge、Chrome，理论兼容所有浏览器。火狐（Firefox）需要把随包的那张证书也装进火狐自己的列表里，不做这一步的话，游戏里的图片可能显示不出来。

会占多少硬盘？

就是它帮你存下来的那些游戏资料本身，刚开始很小，玩得越久越多。控制台里可以按类型查看和清理 —— 清理只删你选的那一类，删掉的资料游戏下次需要时会自己重新下载。

会不会影响我电脑上的别的东西？

程序只在你自己的电脑内部工作，不对外开放任何东西。它启动时会接管一次你系统里的上网设置，所以退出时请用它托盘菜单里的「退出」，不要强行结束它 —— 那样设置可能不会还原回来。

为什么「缓存命中」不涨？

先看控制台顶部的状态提示。常见原因有两个：一是浏览器还在用它自己的缓存，没有把请求交给本程序（重启浏览器即可）；二是系统里的「自动配置脚本」没有指向本程序，控制台里可以重新检测并修复。

能装几台电脑？需要什么系统？

自己用没问题，请只用于你自己的电脑和账号（见下面的声明）。系统要求是 64 位的 Windows 10 或 Windows 11。

它会修改游戏本身吗？

不会。它不碰游戏文件、不改游戏代码，只是在游戏和网络之间做一次「有本地副本就先读本地」的选择。
